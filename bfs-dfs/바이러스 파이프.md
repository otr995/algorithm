## 🧠 1. 첫 접근 (아이디어)
> 문제를 처음 보고 떠올린 생각 / 직관
~~어렵다~~
- 감염 배양체 파이프 타입을 관리하는 자료구조, 감염 배양체 노드를 관리하는 자료구조를 갖고 있어야 할 것 같다
- k가 10 미만이고, 노드 수가 100 이하이기 때문에 백 트래킹을 이용한 재귀적 구현으로 최댓값을 구하자
- 감염된 노드끼리 연결된 파이프 타입을 제외하는 코드가 필요하다




### 착각한 부분
- 굳이 감염된 배양체와 연결된 파이프 타입을 관리할 필요가 없음 -> 가지치기 효과가 구현 복잡도 대비 미비함

### 문제점
- 구현 난이도가 어려워 보임

### 사고 전환
- DFS : k번째 각 선택마다 A,B,C 타입을 모두 탐색
- BFS : 감염을 BFS로 구현

## ❌ 2. 틀린 접근 / 시행착오

### 시도 1

```java
import java.util.*;
class Solution {
    public int solution(int n, int infection, int[][] edges, int k) {
        ArrayList<ArrayList<int[]>> edge = new ArrayList<>();
        Set<Integer> ifnode = new HashSet<>();
        
        for(int i=0; i<=n; i++){
            edge.add(new ArrayList<>());
        }
        
        for(int i=0; i<edges.length; i++){
            edge.get(edges[i][0]).add(new int[]{edges[i][1],edges[i][2]});
            edge.get(edges[i][1]).add(new int[]{edges[i][0],edges[i][2]});
        }
        ifnode.add(infection);
        
        int answer = infect(edge,ifnode,0,k);
    
        return answer;
    }
    
    public int infect(ArrayList<ArrayList<int[]>> edge, 
                      Set<Integer> ifnode, int depth, int k){
        
        int max = ifnode.size();
        if (depth==k) return max;
        
        for(int i=1; i<4; i++){
            Set<Integer> next = new HashSet<>(spread(ifnode,i,edge));
            if(next.size() == max) continue;
            max = Math.max(max,infect(edge,next,depth+1,k));
        }
        return max;
    }
    
    public Set<Integer> spread(Set<Integer> ifnode,int type,
                               ArrayList<ArrayList<int[]>> edge){
        
        Queue<Integer> q = new LinkedList<>();
        
        for(Integer n : ifnode){
            q.add(n);
        }
        
        while(!q.isEmpty()){
            int curr = q.poll();
            
            for(int[] info : edge.get(curr)){
                if(info[1] == type) {
                    q.add(info[0]);
                    ifnode.add(info[0]);
                }
            }
        }
        return ifnode;
    }
}

```

```java
        }
        ifnode.add(infection);
        
        int answer = infect(edge,ifnode,0,k);
    
        return answer;
    }
    
    public int infect(ArrayList<ArrayList<int[]>> edge, 
                      Set<Integer> ifnode, int depth, int k){
        
        int max = ifnode.size();
        if (depth==k) return max;
        
        for(int i=1; i<4; i++){
            Set<Integer> next = new HashSet<>(spread(ifnode,i,edge));
            if(next.size() == max) continue;
            max = Math.max(max,infect(edge,next,depth+1,k));
        }
        return max;
    }
    
    public Set<Integer> spread(Set<Integer> ifnode,int type,
                               ArrayList<ArrayList<int[]>> edge){
        boolean[] visited = new boolean[edge.size()];
        Queue<Integer> q = new LinkedList<>();
        
        for(Integer n : ifnode){
            visited[n] = true;
            q.add(n);
        }
        
        while(!q.isEmpty()){
            int curr = q.poll();
            
            for(int[] info : edge.get(curr)){
                if(visited[info[0]]) continue;
                if(info[1]!=type) continue;
                
                q.add(info[0]);
                visited[info[0]] = true;
                ifnode.add(info[0]);
            }
        }
        return ifnode;
    }
}

```

## 🔍 3. 핵심 관찰 (문제 제대로 이해하기)

- 중요한 조건:
    - 파이프 타입은 A,B,C
    - 특정 타입 파이프를 열 때, 인접한 같은 타입 파이프와 연결된 배양체들은 연쇄적으로 감염됨
    - k번 선택 동안 감염시킬 수 있는 최대 배양체 수를 구해야함
- 놓쳤던 부분:
    - 감염 확산은 단순 인접 노드 추가가 아니라 BFS로 연쇄처리해야 함
    - bfs에서 방문여부 체크를 안하면 무한루프에 빠질 수도 있다..
- 핵심 포인트:
    - DFS : 파이프 타입 선택 순서 탐색
    - BFS : 선택한 파이프 타입으로 감염 확산
    - DFS 분기마다 감염 상태가 섞이지 않도록 Set을 복사해서 사용해야 함

## ✅ 4. 최종 접근 방법

- 전체 전략:
    - k번 동안 선택할 파이프 타입의 모든 경우를 DBS로 탐색
    - 각 단계에서 선택한 파이프 타입을 기준으로 BFS를 사용하여 감염 확산을 구함
    - 감염 확산시 전 감염 수와 동일하면 이어지지 않는 경우이기 때문에 재귀 종료
- 사용한 자료구조:
    - ArrayList<ArrayList<int[]>> : 그래프 인접 리스트
    - Set<Integer> : 현재 감염 배양체
    - Queue<Integer> : 감염 확산 처리
    - boolean[] : BFS 방문 여부
- 로직 흐름:
    1. edges 정보를 바탕으로 양방향 그래프를 만듬
    2. DFS로 매 단계마다 A,B,C 타입 선택
    3. 선택한 타입에 대한 감염을 확산하고 감염 집합을 새로 만들어 최대 감염 수를 갱신

## 💻 5. 최종 코드

```java
import java.util.*;
class Solution {
    public int solution(int n, int infection, int[][] edges, int k) {
        ArrayList<ArrayList<int[]>> edge = new ArrayList<>();
        Set<Integer> ifnode = new HashSet<>();
        
        for(int i=0; i<=n; i++){
            edge.add(new ArrayList<>());
        }
        
        for(int i=0; i<edges.length; i++){
            edge.get(edges[i][0]).add(new int[]{edges[i][1],edges[i][2]});
            edge.get(edges[i][1]).add(new int[]{edges[i][0],edges[i][2]});
        }
        ifnode.add(infection);
        
        int answer = infect(edge,ifnode,0,k);
    
        return answer;
    }
    
    public int infect(ArrayList<ArrayList<int[]>> edge, 
                      Set<Integer> ifnode, int depth, int k){
        
        int max = ifnode.size();
        if (depth==k) return max;
        
        for(int i=1; i<4; i++){
            Set<Integer> next = new HashSet<>(spread(ifnode,i,edge));
            if(next.size() == max) continue;
            max = Math.max(max,infect(edge,next,depth+1,k));
        }
        return max;
    }
    
    public Set<Integer> spread(Set<Integer> ifnode,int type,
                               ArrayList<ArrayList<int[]>> edge){
        boolean[] visited = new boolean[edge.size()];
        Queue<Integer> q = new LinkedList<>();
        Set<Integer> next = new HashSet<>(ifnode);
        
        for(Integer n : ifnode){
            visited[n] = true;
            q.add(n);
        }
        
        while(!q.isEmpty()){
            int curr = q.poll();
            
            for(int[] info : edge.get(curr)){
                if(visited[info[0]]) continue;
                if(info[1]!=type) continue;
                
                q.add(info[0]);
                visited[info[0]] = true;
                next.add(info[0]);
                
            }
        }
        
        return next;
    }
}

```

## ⏱ 6. 시간 / 공간 복잡도

- 시간 복잡도: O(3^k × (N + E))
    - 파이프 타입 선택 경우의 수는 최대 3^k
- 공간 복잡도: O(N + E)
    - 그래프 저장 공간
    - 감염 노드 Set
    - BFS Queue 및 visited

## 📚 8. 배운 점 (핵심 정리)

- 완전탐색 범위가 작다면 복잡한 상태 관리보다는 단순 DFS가 쉽고 안전할 수 있음
- 그래프 -> 연쇄적 : DFS/BFS로 처리
- 재귀 탐색에서는 현재 상태를 직접 수정하지 않고, 복사본을 만들어 다음 분기로 넘기는 것이 안전
