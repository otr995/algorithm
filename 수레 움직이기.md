# 프로그래머스 [PCCP 기출문제] 4번 / 수레 움직이기

---

## 🧠 1. 첫 접근 (아이디어)
> 문제를 처음 보고 떠올린 생각 / 직관

- 각 수레의 경로를 최소화하기 보다는 모든 수레의 도착 최대 시간을 최소화 해야 함
- 모든 수레의 도착 시간을 전수 조사
- DFS와 백트래킹을 사용 / min 값보다 작으면 중지

### 착각한 부분
- 4*4 사이즈라서 메모리가 작을 줄 알았지만, 객체 2개를 4방향으로 이동하는 경우의 수가 많음

### 문제점
- 메모리가 커서 시간, 공간이 초과될 확률이 높고 제약 사항을 구현하기 까다로움

### 사고 전환
- BFS를 사용하되 각 수레의 최단경로를 구하지 말고 전체 시스템의 최단 경로를 구하자
- 상태 관리와 제약 사항 구현을 해야함

## ❌ 2. 틀린 접근 / 시행착오

### 시도 1

[code]
    import java.util.*;
    class Solution {
        public int solution(int[][] maze) {
            int answer = 0;
            int n = maze.length;
            int m = maze[0].length;
            int rx=0, ry=0;
            int bx=0, by=0;
            int time = 0;
            boolean[][][][] visited = new boolean[n][m][n][m];
            int[] dx = {1,-1,0,0};
            int[] dy = {0,0,1,-1};
            Queue<int[]> q = new LinkedList<>();
            boolean r=false, b=false;
            
            for(int i=0; i<n; i++){
                for(int j=0; j<m; j++){
                    if(maze[i][j] == 1){
                        rx = j;
                        ry = i;
                    }
                    else if(maze[i][j] == 2){
                        bx = j;
                        by = i;
                    }
                }
            }
            q.add(new int[]{rx,ry,bx,by});
            
            while(!q.isEmpty()){
                int[] curr = q.poll();
                visited[curr[1]][curr[0]][curr[3]][curr[2]] = true;
                
                if(maze[curr[1]][curr[0]] == 3) r = true;
                if(maze[curr[3]][curr[2]] == 4) b = true;
                
                if(r && b) return time;
                
                for(int i=0; i<4; i++){
                    int nrx = curr[0] + dx[i];
                    int nry = curr[1] + dy[i];
                    
                    if(maze[nry][nrx] == 5) continue;
                    
                    if(r)
                    {
                        nrx = curr[0];
                        nry = curr[1];
                    }
                    for(int j=0; j<4; j++){
                        int nbx = curr[2] + dx[j];
                        int nby = curr[3] + dx[j];
                        if(b)
                        {
                            nbx = curr[2];
                            nby = curr[3];
                        }
                        if(maze[nby][nbx] == 5) continue;
                        if(nrx >= m || nbx >= m || nry >=n || nby >= n) continue;
                        if(nrx == bx && nbx == rx && nry == by && nby == ry) continue;
                        if(nrx == nbx && nry == nby) continue;
                        
                        if(visited[nry][nrx][nby][nbx]) continue;
                        
                        time++;
                        q.add(new int[]{nrx,nry,nbx,nby});
                    }
                }
            }
            return time;
        }
    }
[/code]

- ❗ 왜 틀렸는지:
    - 1. IOE
        - nx, ny 범위 확인 전에 벽 (maze == 5) 을 확인
        - 범위 체크에서 음수 값 확인 안함
    - 2. 전역 변수 관리
        - 수레 도착 여부를 전역으로 관리함 -> queue 마다 상태를 확인해야 함
        - time을 전역으로 관리해서 time++으로 처리함 -> queue 마다 상태를 확인해야 함
    - 3. visited 상태 관리 시점
        - queue에 추가할 때 true로 하지 않고 poll()하고 추가함 -> 중복 확인을 하게됨
    - 4. dy i,j 변수 오타

    class Solution {
        public int solution(int[][] maze) {
            int n = maze.length;
            int m = maze[0].length;
            int rx=0, ry=0;
            int bx=0, by=0;
            boolean[][][][] visited = new boolean[n][m][n][m];
            int[] dx = {1,-1,0,0};
            int[] dy = {0,0,1,-1};

            for(int i=0; i<n; i++){
                for(int j=0; j<m; j++){

                        ry = i;
                    }
                    else if(maze[i][j] == 2){
                        bx = j;
                        by = i;
                    }
                }

            q.add(new int[]{rx,ry,bx,by,0});
            visited[ry][rx][by][bx] = true;
            
            while(!q.isEmpty()){
                int[] curr = q.poll();
                int time = curr[4];
                
                boolean r=false, b=false;
                
                
                if(maze[curr[1]][curr[0]] == 3) r = true;
                if(maze[curr[3]][curr[2]] == 4) b = true;
                
                if(r && b) return time;
                
                for(int i=0; i<4; i++){
                    int nrx = curr[0] + dx[i];
                    int nry = curr[1] + dy[i];
                    
                    if(r)
                    {
                        nrx = curr[0];
                        nry = curr[1];
                    }
                    
                    if(nrx >= m || nrx < 0 || nry >=n || nry < 0) continue;
                    if(maze[nry][nrx] == 5) continue;
                
                    for(int j=0; j<4; j++){
                        int nbx = curr[2] + dx[j];
                        int nby = curr[3] + dy[j];
                        if(b)
                        {
                            nbx = curr[2];
                            nby = curr[3];
                        }
                    
                        if(nbx >= m || nbx < 0 || nby >= n || nby < 0) continue;
                        if(maze[nby][nbx] == 5) continue;
                        
                        if(nrx == curr[2] && nbx == curr[0] && 
                        nry == curr[3] && nby == curr[1]) continue;
                        
                        if(nrx == nbx && nry == nby) continue;
                        if(visited[nry][nrx][nby][nbx]) continue;
                        
                        visited[nry][nrx][nby][nbx] = true;
                        
                        q.add(new int[]{nrx,nry,nbx,nby,time+1});
                    }
                }
            }
            return 0;
        }

- ❗ 왜 틀렸는지:
    - 4차원 boolean 배열로 2개의 객체 전체 상태는 관리가 되지만, 각 수레가 이동한 경로 체크가 되지 않음
    - 백 트래킹이 필요하다고 다시 생각..
    - 재귀말고 stack으로 구현해야 경우의 수에 따라 스택이 비약적으로 커지지 않을 것 같음
    - 다시 DFS + 백 트래킹 전수 조사로 변경

## 🔍 3. 핵심 관찰 (문제 제대로 이해하기)

- 중요한 조건:
    - 수레는 자신이 방문했던 칸으로 이동할 수 없음
    - 도착 칸에 위치한 수레는 고정됨
    - 같은 칸에 수레가 위치할 수 없음
    - 수레끼리 자리를 바꿀 수 없음
- 놓쳤던 부분:
    - 최단 경로임을 보고 BFS로 생각했으나, 경로 제약이 있기 때문에 백 트래킹 유리한 DFS가 나을 것으로 보임
    - 경우의 수가 많을 때 재귀적으로 dfs을 구현하면 스택 메모리가 늘어나는 것을 어디까지 조심해야할 지 고민해야 함
    - bfs에서 4차원으로 구현하면 경로가 다른데 같은 위치 상태인 경우를 구분하지 못함
- 핵심 포인트:
    - 상태는 하나의 시스템으로 봐야 함
    - 하지만 제약은 개별 경로에 있음
    - 상태 + 경로 의존이 동시에 존재하기 때문에 일반 BFS처럼 풀면 안됨
    - DFS + 백트래킹으로 푸는 것이 자연스러움

## ✅ 4. 최종 접근 방법

- 전체 전략: 
    - DFS + 백 트래킹 (재귀적 구현)
- 사용한 자료구조: 
    - 배열 
- 로직 흐름:
    1. 각 수레 시작,도착 좌표 초기화 및 각 수레 방문 여부 배열 초기화 
    2. dfs 시작점 진입 
    3. 최소 시간 비교를 통한 최적화
    4. 도착 여부 확인
    5. 다음 진입 좌표 제약 사항 체크 및 이동
    6. 백트래킹

## 💻 5. 최종 코드

[code]
    import java.util.*;

    class Solution {
        int n, m;
        int[][] maze;
        int answer = Integer.MAX_VALUE;

        int redStartX, redStartY;
        int blueStartX, blueStartY;

        int redEndX, redEndY;
        int blueEndX, blueEndY;

        boolean[][] redVisited;
        boolean[][] blueVisited;

        int[] dx = {1, -1, 0, 0};
        int[] dy = {0, 0, 1, -1};

        public int solution(int[][] maze) {
            this.maze = maze;
            n = maze.length;
            m = maze[0].length;

            redVisited = new boolean[n][m];
            blueVisited = new boolean[n][m];

            for (int y = 0; y < n; y++) {
                for (int x = 0; x < m; x++) {
                    if (maze[y][x] == 1) {
                        redStartX = x;
                        redStartY = y;
                    } else if (maze[y][x] == 2) {
                        blueStartX = x;
                        blueStartY = y;
                    } else if (maze[y][x] == 3) {
                        redEndX = x;
                        redEndY = y;
                    } else if (maze[y][x] == 4) {
                        blueEndX = x;
                        blueEndY = y;
                    }
                }
            }

            redVisited[redStartY][redStartX] = true;
            blueVisited[blueStartY][blueStartX] = true;

            dfs(redStartX, redStartY, blueStartX, blueStartY, 0);

            return answer == Integer.MAX_VALUE ? 0 : answer;
        }

        void dfs(int rx, int ry, int bx, int by, int time) {
            if (time >= answer) return;

            boolean redArrived = rx == redEndX && ry == redEndY;
            boolean blueArrived = bx == blueEndX && by == blueEndY;

            if (redArrived && blueArrived) {
                answer = Math.min(answer, time);
                return;
            }

            for (int i = 0; i < 4; i++) {
                int nrx = rx;
                int nry = ry;

                if (!redArrived) {
                    nrx = rx + dx[i];
                    nry = ry + dy[i];

                    if (!isValid(nrx, nry)) continue;
                    if (redVisited[nry][nrx]) continue;
                }

                for (int j = 0; j < 4; j++) {
                    int nbx = bx;
                    int nby = by;

                    if (!blueArrived) {
                        nbx = bx + dx[j];
                        nby = by + dy[j];

                        if (!isValid(nbx, nby)) continue;
                        if (blueVisited[nby][nbx]) continue;
                    }

                    // 같은 칸으로 이동 불가
                    if (nrx == nbx && nry == nby) continue;

                    // 서로 자리 교환 불가
                    if (nrx == bx && nry == by && nbx == rx && nby == ry) continue;

                    if (!redArrived) redVisited[nry][nrx] = true;
                    if (!blueArrived) blueVisited[nby][nbx] = true;

                    dfs(nrx, nry, nbx, nby, time + 1);

                    if (!redArrived) redVisited[nry][nrx] = false;
                    if (!blueArrived) blueVisited[nby][nbx] = false;
                }
            }
        }

        boolean isValid(int x, int y) {
            return x >= 0 && x < m &&
                y >= 0 && y < n &&
                maze[y][x] != 5;
        }
    }
[/code]
