# 프로그래머스 [PCCP 기출문제] 3번 / 아날로그 시계

---

## 🧠 1. 첫 접근 (아이디어)
> 문제를 처음 보고 떠올린 생각 / 직관

- 1초를 기준으로 시침, 분침, 초침이 움직이는 각도를 계산하자
- mod 360으로 시계 안 각도를 유지하면서 겹치는 부분을 체크하기

### 착각한 부분
- 1초 단위로 보면 연속된 이벤트를 모두 체크하지 못함 (0.*초 단위 이벤트)

### 문제점
- 1초 기준 계산으로는 모든 경우의 수를 계산하지 못함
- double로 해도 부동소수점 계산에서 오류가 생길 수 있음

### 사고 전환
- 수학적으로 겹치는 규칙?을 구해서 풀기

## ❌ 2. 틀린 접근 / 시행착오

### 시도 1

```java
class Solution {
    public int solution(int h1, int m1, int s1, int h2, int m2, int s2) {
        int answer = 0;

        int start = h1 * 3600 + m1 * 60 + s1;
        int end = h2 * 3600 + m2 * 60 + s2;

        double hour = (h1 % 12) * 30 + m1 * 0.5 + s1 * (1.0 / 120);
        double minute = m1 * 6 + s1 * 0.1;
        double second = s1 * 6;

        double eps = 1e-6;

        for (int t = start; t < end; t++) {

            hour += 1.0 / 120;
            minute += 0.1;
            second += 6;

            hour %= 360;
            minute %= 360;
            second %= 360;

            boolean hm = Math.abs(hour - minute) < eps;
            boolean hs = Math.abs(hour - second) < eps;
            boolean ms = Math.abs(minute - second) < eps;

            if (hm) answer++;
            if (hs) answer++;
            if (ms) answer++;

            if (hm && hs && ms) {
                answer -= 2; 
            }
        }

        return answer;
    }
}

```

- ❗ 왜 틀렸는지:
    - 1초 단위 계산으로 연속된 상황에서는 이벤트를 감지하지 못함
    - 1.556초에서 겹치는 일이 발생하면 알람 이벤트를 감지하지 못함..

### 시도 2

```java
class Solution {
    public int solution(int h1, int m1, int s1, int h2, int m2, int s2) {
        int answer = 0;

        int start = h1 * 3600 + m1 * 60 + s1;
        int end = h2 * 3600 + m2 * 60 + s2;
        
        return count(end) - count(start);
    }
    
    public int count(int t){
        int m = (59 * t) / (10*360);
        int h = (719 * t) / (360 * 120);
        
        int result = m + h + 2; 
        
        return t > 43200 ? result-2 : result-1;
    }
}
```
- ❗ 왜 틀렸는지:
    - 0~start : a구간 , 0~end : a+b 구간, 겹치는 구간 : b구간일 때, b구간은 폐구간이기 때문에 a + b - a를 하면 b구간 시작점은 포함되지 않음
    - count(end) - count(start)에서 start 시작점에서 겹칠 때 카운팅되지 않는 오류가 있었음

## 🔍 3. 핵심 관찰 (문제 제대로 이해하기)

- 중요한 조건:
    - [a,b] 사이 초침&분침, 초침&시침이 겹치는 개수
- 놓쳤던 부분:
    - 초침&시침&분침이 모두 겹치는 경우의 수는 0시(12시)밖에 없음
    - a+b - a로 하면 b구간 시작점은 카운팅 되지 않음
- 핵심 포인트:
    - 시뮬레이션으로 하면 1.xxxx초 에서 발생하는 이벤트는 카운팅할 수 없음
    - 수학적 풀이를 통한 풀이가 필요
    - 구간과 중복처리에 대한 처리가 필요
    - 각 침의 초에 따른 각도변화값을 치환
    - S(t) = M(t) (mod 360), S(t) = H(t) (mod 360)

## ✅ 4. 최종 접근 방법

- 전체 전략:
    - count함수 : 초침&분침이 겹치는 개수 + 초침&시침이 겹치는 개수 - (구간에서 세 침이 모두 겹치는 경우)
    - count(end) - count(start) 로 (a,b] 구간 구하고, a구간에서 초침&분침 혹은 초침&시침이 겹치는지 확인
- 사용한 자료구조:
    - X
- 로직 흐름:
    1. 각 시간(start,end)를 초로 변환
    2. count 함수에서 00:00:00 ~ start (혹은 end)까지 겹치는 개수를 구함
    3. start에서 겹치는지 확인하여 겹치면 answer에 더해줌

## 💻 5. 최종 코드

```java
class Solution {
    public int solution(int h1, int m1, int s1, int h2, int m2, int s2) {
        int start = h1 * 3600 + m1 * 60 + s1;
        int end = h2 * 3600 + m2 * 60 + s2;
        
        int answer = count(end) - count(start);
        
        if((int)((start * 59) % 3600) == 0 ||
           (int)((start * 719) % (360*120)) == 0) answer++;
        return answer;
    }
    
    public int count(int t){
        int m = (59 * t) / 3600;
        int h = (719 * t) / 43200;
        
        int result = m + h; 
        
        return t >= 43200 ? result-2 : result-1;
    }
}
```
