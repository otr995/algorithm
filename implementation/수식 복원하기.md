## ❌ 2. 틀린 접근 / 시행착오

### 시도 1

```java
import java.util.*;
class Solution {
    public ArrayList<String> solution(String[] expressions) {
        ArrayList<String> myst = new ArrayList<>();
        Set<Integer> set = new HashSet<>();
        
        int n = max(expressions);
        
        for(int i=n; i<10; i++){
            set.add(i+1);
        }
        
        for(String exp : expressions){
            String[] sp = exp.split(" ");
            if(sp[4].equals("X")){
                myst.add(exp);
            }
            else{
                check(sp, set);
            }
        }
        
        ArrayList<String> answer = new ArrayList<>();
        for(int i=0; i<myst.size(); i++){
            int value = recover(set, myst.get(i).split(" "));
            
            if(value != -1){
                answer.add(myst.get(i).replace("X", value + ""));
            }
        }
        
        return answer;
    }
    
    public int max(String[] exps){
        int max = 2;
        for(String exp : exps){
            String[] sp = exp.split(" ");
            for(int i=0; i<=4; i+=2){
                if(sp[i].equals("X")) continue;
                
                for(char c : sp[i].toCharArray()){
                    max = Math.max(max, c-'0');
                }
            }
        }
        return max;
    }
    
    public void check(String[] str, Set<Integer> set){
        Iterator<Integer> it = set.iterator();
        
        while(it.hasNext()){
            int base = it.next();
            
            int a = toDecimal(str[0], base);
            int b = toDecimal(str[2], base);
            int c = toDecimal(str[4], base);
            
            int result = str[1].equals("+") ? a + b : a - b;
            
            if(result != c){
                it.remove();
            }
        }
    }
    
    public int toDecimal(String num, int base){
        int result = 0;
        
        for(char c : num.toCharArray()){
            result = result * base + (c - '0');
        }
        return result;
    }
    
    public int toN(String str, Integer n){
        int num = Integer.parseInt(str);
        StringBuilder sb = new StringBuilder();
        
        while(num > 0){
            sb.append(num % n);
            num /= n;
        }
        
        return Integer.parseInt(sb.reverse().toString());
    }
    
    
    public int recover(Set<Integer> set, String[] str){
        Iterator<Integer> it = set.iterator();
        
        Integer i = it.next();
        it.remove();
        int a = toN(str[0], i);
        int b = toN(str[2], i);
        
        int result = str[1].equals("+") ? a+b : a-b;
        
        while(it.hasNext()){
            Integer n = it.next();
            int num1 = toN(str[0], n);
            int num2 = toN(str[2], n);
            
            int sum = str[1].equals("+") ? num1+num2 : num1-num2;
            
            if(result != sum) return -1;
        }
        return result;
    }
}

```

- ❗ 왜 틀렸는지:
    - iterator의 next() 메소드가 다음 원소만 가져오는줄 알아서 후보 진법 계산이 달라질 수 있었음
    - n진법 + n진법 = X 수식을 복원 후 확인하는 과정에서 10진법으로 변환한 것을 더한 것을 다시 n진법으로 변환한 수를 비교해야 하는데 n진법인 수를 다시 n진법(toN)으로 변환하여 비교하여 잘못된 결과를 받음
    - n진법 변환 과정에서 a+b or a-b가 0인 경우에는 StringBuilder에 아무것도 추가되지 않고 반환됨
    - max를 구하고 후보 진법을 추가하는 과정에서 10진법까지 추가됨 (i<10)

import java.util.*;
class Solution {
    public ArrayList<String> solution(String[] expressions) {
        ArrayList<String> myst = new ArrayList<>();
        Set<Integer> set = new HashSet<>();
        
        int n = max(expressions);
        
        for(int i=n; i<9; i++){
            set.add(i+1);
        }
        
        for(String exp : expressions){
            String[] sp = exp.split(" ");
            if(sp[4].equals("X")){
                myst.add(exp);
            }
            else{
                check(sp, set);
            }
        }
        
        ArrayList<String> answer = new ArrayList<>();
        for(int i=0; i<myst.size(); i++){
            int value = recover(set, myst.get(i).split(" "));
            
            if(value != -1){
                answer.add(myst.get(i).replace("X", value + ""));
            }
            else{
                answer.add(myst.get(i).replace("X","?"));
            }
        }
        
        return answer;
    }
    
    public int max(String[] exps){
        int max = 2;
        for(String exp : exps){
            String[] sp = exp.split(" ");
            for(int i=0; i<=4; i+=2){
                if(sp[i].equals("X")) continue;
                
                for(char c : sp[i].toCharArray()){
                    max = Math.max(max, c-'0');
                }
            }
        }
        return max;
    }
    
    public void check(String[] str, Set<Integer> set){
        Iterator<Integer> it = set.iterator();
        
        while(it.hasNext()){
            int base = it.next();
            
            int a = toDecimal(str[0], base);
            int b = toDecimal(str[2], base);
            int c = toDecimal(str[4], base);
            
            int result = str[1].equals("+") ? a + b : a - b;
            
            if(result != c){
                it.remove();
            }
        }
    }
    
    public int toDecimal(String num, int base){
        int result = 0;
        
        for(char c : num.toCharArray()){
            result = result * base + (c - '0');
        }
        return result;
    }
    
    public int toN(int num, Integer n){
        if(num == 0) return 0;
        StringBuilder sb = new StringBuilder();
        
        while(num > 0){
            sb.append(num % n);
            num /= n;
        }
        
        return Integer.parseInt(sb.reverse().toString());
    }
    
    
    public int recover(Set<Integer> set, String[] str){
        Iterator<Integer> it = set.iterator();
        
        Integer i = it.next();
        
        int a = toDecimal(str[0], i);
        int b = toDecimal(str[2], i);
        
        int result = str[1].equals("+") ? toN(a+b,i) : toN(a-b,i);
        
        while(it.hasNext()){
            Integer n = it.next();
            int num1 = toDecimal(str[0], n);
            int num2 = toDecimal(str[2], n);
            
            int sum = str[1].equals("+") ? toN(num1+num2,n) : toN(num1-num2,n);
            
            if(result != sum) return -1;
        }
        return result;
    }
}

## 🔍 3. 핵심 관찰 (문제 제대로 이해하기)

- 중요한 조건:
    - 주어진 수식들은 특정 진법에서 항상 성립하며, 가능한 진법은 2진법 ~ 9진법이다.
    - X가 포함된 수식은 결과값이 지워진 상태이며, 가능한 모든 진법에서 결과가 동일할 때만 복원할 수 있다.
    - 결과값이 서로 다른 진법에서 다르게 나오면 ?를 출력해야 한다.
- 놓쳤던 부분:
    - 가능한 진법 후보가 여러 개여도, 계산 결과가 모두 같다면 정답을 확정할 수 있다는 점.
    - 진법 변환 결과를 숫자(int)가 아닌 문자열 기준으로 비교해야 한다는 점.
    - 컬렉션 순회 중 remove() 시 Iterator를 사용해야 한다는 점.
- 핵심 포인트:
    - 후보 진법을 줄이는 과정과 남은 진법들로 결과 비교를 분리해서 생각해야 한다.
    - 계산은 모두 10진법으로 수행한 뒤, 다시 해당 진법 문자열로 변환해서 비교해야 한다.

## ✅ 4. 최종 접근 방법

- 전체 전략:
    -가능한 모든 진법 후보를 저장한 뒤 결과값이 존재하는 수식들로 후보 진법을 제거하고, X가 포함된 수식은 남은 진법들에서 
    계산 결과를 비교하여 복원 여부를 판단했다.
-사용한 자료구조:
    -HashSet<Integer> : 가능한 진법 후보 저장
    -ArrayList<String> : X가 포함된 수식 저장
-로직 흐름:
    1. 수식에 등장하는 가장 큰 숫자를 기준으로 가능한 진법 후보를 생성한다.
    2. 결과값이 존재하는 수식들을 이용해 성립하지 않는 진법 후보를 제거한다.
    3. X가 포함된 수식들을 남은 진법 후보들로 계산한 뒤,결과 문자열이 모두 같으면 해당 값을 다르면 ?를 반환한다.

## 📚 8. 배운 점 (핵심 정리)

- for-each문은 내부적으로 Iterator를 사용해 컬렉션을 순회하고, 순회 중 컬렉션 객체에서 직접 remove()를 호출하면 Iterator가 인식하고 있는 컬렉션 상태와 실제 상태가 달라져 오류가 발생함. 따라서 순회 중 요소를 삭제할 경우엔 Itreator 객체의 remove() 메서드를 사용해야 함. 
- 계산은 10진법 기준으로 수행하고, 출력 시 다시 해당 진법 문자열로 변환
