# [2025 카카오 하반기 1차] 노란불 신호등

---

## 🧠 1. 첫 접근 (아이디어)
> 문제를 처음 보고 떠올린 생각 / 직관

- 스케줄링인줄 알았으나, 각 신호등마다 주기를 계산해서 모두 겹치는지 확인하는 과정이 있으면 되겠군!
- 겹치지 않는 경우를 확인해야 하는데, 시뮬레이션으로 하는건 아닌 것 같고 수학적인 풀이가 있으면 좋을 것 같다
- 등차수열을 이용해서 풀어볼 수 있을 것 같음

### 착각한 부분
- 노란불이 들어오는 시간이 모두 1초인줄 알았다..

### 문제점
- 등차수열로는 방정식을 못 품
- 노란불이 1초 이상 켜져있으면 등차수열이 틀림

### 사고 전환
- 각 신호등의 최소 주기만큼 반복하면서 시뮬레이션을 돌리자
- 최소 주기는 각 신호등 G+B+Y의 최소 공배수
- 유클리드 호제법을 이용해서 최소 공배수 구하기 (몰랐음!)

## 🔍 3. 핵심 관찰 (문제 제대로 이해하기)

- 중요한 조건:
    - 모든 신호등이 노란불이 되는 가장 빠른 시각을 반환
    - [G,Y,R] 형태로 주어짐
    - 1<= G,Y,R <= 18  즉 노란불도 1초 이상 켜져있을 수 있음
- 놓쳤던 부분:
    - 노란불이 1초만 켜지는 줄 알았음
    - 최소 주기가 모든 신호등의 G+Y+R을 곱하면 되는 줄 알았음
- 핵심 포인트:
    - 각 신호등의 최소 주기, 즉 최소 공배수만큼 반복하면서 완전 탐색을 실시

---

## ✅ 4. 최종 접근 방법

- 전체 전략:
    - 최대 공약수 알고리즘으로 최소 공배수를 구함
    - 최소 공배수만큼 반복하면서 (1초씩 증가하면서) 모든 신호등이 노란불인지 확인함
- 사용한 자료구조:
    - boolean : 신호등 상태 확인
    - int[] : 각 신호등 정보 및 주기 정보
- 로직 흐름:
    1. 최소 공배수를 구함
    2. 최소 공배수만큼 반복문 실행
    3. 각 신호등이 현재 시간(초)에서 노란불인지 확인함
    4. 모든 신호등이 노란불이면 현재 시간을 반환, 반복문이 종료되면 -1 반환

## 💻 5. 최종 코드

```java
class Solution {
    public int solution(int[][] signals) {
        int lcm = lcm(signals);
        boolean state;
        for(int i=1; i<lcm; i++){
            state = true;
            for(int j=0; j<signals.length; j++){
                if(!check(signals[j],i)) state = false;
            }
            if(state) return i;
        }
        
        return -1;
    }
    public boolean check(int[] signal, int time){
        int g = signal[0];
        int y = signal[1];
        int r = signal[2];
        int sum = g+y+r;
        
        for(int i=0; i<y; i++){
            if((time + r + i) % sum == 0) return true;
        }
        return false;
    }
    
    public int gcd(int a, int b){
        while(b!=0){
            int temp = b;
            b = a%b;
            a = temp;
        }
        return a;
    }
    public int lcm(int[][] signals){
        int n = signals.length;
        int[] arr = new int[n];
        
        for(int i=0; i<n; i++){
            int sum = 0;
            for(int j=0; j<3; j++){
                sum += signals[i][j];
            }
            arr[i] = sum;
        }
        
        int result = arr[0];
        for(int i=1; i<n; i++){
           result = result * arr[i] / gcd(result,arr[i]); 
        }
        
        return result;
    }
}

```
